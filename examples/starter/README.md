# Starter Examples

`openminion/examples/starter/` holds copy-first snippets for the most common
runtime and extension surfaces. The extension imports match the current
scaffold output and may evolve while OpenMinion is pre-1.0.

Use these files when you want the smallest possible starting point for:

1. a runtime integration,
2. a channel,
3. a plugin,
4. a tool,
5. a plugin manifest,
6. a one-turn runtime quickstart.

## Run the quickstart

Create a credential-free echo configuration once, then run the example:

```bash
openminion config init --provider echo
python examples/starter/quickstart.py "Hello from the Python API"
```

The plugin discovery pair is `hello.py` and `hello.manifest.json`. The tool
example uses the same execution contract generated by
`openminion scaffold tool`.
